# English for Data & Translation

Programme personnel de perfectionnement en grammaire anglaise, du niveau B1 vers B2+, sur 24 semaines.
Chaque chapitre associe un point de grammaire, son usage dans les documents de données (rapports, statistique, Power BI, SQL) et les pièges de traduction français-anglais.

Auteur : TRE BI

## Contenu

- 6 modules, 24 chapitres (un par semaine)
- Leçons avec tableaux, exemples bilingues, encadrés « Piège du francophone », « Focus données », « Focus traduction »
- 397 items d'exercices : textes à trous et QCM corrigés automatiquement, traductions avec proposition commentée et auto-évaluation
- Production personnelle à rédiger dans chaque chapitre
- Glossaire de 244 termes, consultable dans les deux langues
- Programme daté à partir d'une date de début, et page de progression (scores par chapitre et par module)

## Publier sur GitHub Pages

1. Créer un dépôt (par exemple `english-program`) et y déposer `index.html` à la racine.
2. Dans **Settings > Pages**, choisir la branche `main` et le dossier `/ (root)`.
3. Le programme est accessible à l'adresse `https://<utilisateur>.github.io/english-program/`.

## Progression

La progression est enregistrée dans le navigateur (localStorage). Pour la sauvegarder ou la retrouver sur un autre appareil, utiliser **Ma progression > Exporter (JSON)**, puis **Importer un fichier**. Le fichier exporté peut être versionné dans le dépôt, par exemple dans `progress/progression.json`.
